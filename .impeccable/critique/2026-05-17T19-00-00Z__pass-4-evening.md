## Priority Issues

**[P2] Esc key conflict with Fullscreen API**
- **What**: Keyboard handler fires `pause()` + `setShowExitGuard(true)` on every Esc keydown, no check for `document.fullscreenElement`. Firefox propagates Esc to JavaScript handlers even when exiting fullscreen — double-action.
- **Why it matters**: On Firefox, pressing Esc to dismiss fullscreen simultaneously pauses the session and opens the exit guard without user intent.
- **Fix**: At the top of the Esc branch, add `if (document.fullscreenElement) return;`

**[P2] Orb size control is entirely undiscoverable**
- **What**: Three white circles bottom-left have aria semantics but no visible label or tooltip.
- **Why it matters**: Zero discoverability for users who don't experiment. Users who'd benefit most (small screens, motor concerns) are least likely to tap ambiguous dots at the edge of a meditation interface.
- **Fix**: Add `title="Orb size"` to the wrapper div, or add a micro-label "orb size" at white/22 above the dots matching keyboard hint style.

**[P2] Paused text fails WCAG AA contrast**
- **What**: `text-white/25` on `#090c0a` ≈ 2.5:1. WCAG AA requires 4.5:1.
- **Why it matters**: A user who accidentally hit Space may believe the app froze.
- **Fix**: Raise to `text-white/55`. Add "space to resume" beneath at white/38.

**[P2] Silent localStorage failure loses completed sessions**
- **What**: `writeStats()` swallows errors silently. Private browsing and iOS restrictions discard session records.
- **Why it matters**: User completes a session, visits Stats, sees "No sessions yet." No explanation.
- **Fix**: Track in-memory alongside localStorage. Show in-memory summary on SessionComplete regardless. Note on stats page when storage unavailable.

**[P2] No count-in buffer before session start**
- **What**: `start()` called on mount. Clock runs while page is loading.
- **Why it matters**: First breath starts mid-render; no moment to settle.
- **Fix**: 2–3 second "Ready" idle state with softly pulsing orb before first breath.

**[P3] iOS Safari: fullscreen button silently fails**
- **What**: `requestFullscreen()` unsupported on iOS Safari. Button renders and taps but does nothing.
- **Fix**: Check `document.fullscreenEnabled` on mount; hide button if false.

## Minor Observations

- "Days practiced" is a streak counter that resets on gaps — misleading label. Change to "Day streak" or use monotonically increasing `uniqueDays.length`.
- `~N min remaining` ticks down by cycle (16s steps), not continuously — can display the same value for 16 seconds. Consider removing after settle in favor of progress bar alone.
- Session duration labels are intentionally rounded; actual durations are 2m56s/5m20s/6m56s/9m52s vs 3/5/7/10 min labels. Acceptable but watch for user expectation mismatch.
- Four-corner layout works on desktop; on 375px portrait phone the corners are much closer to the orb. Needs mobile pass.
- Keyboard hint at white/22 is below useful contrast. Either raise to white/42+ or remove.
- Pause/resume emoji (▶ ⏸) vs text-only everywhere else is a minor consistency gap.

## Questions to Consider

- Is fullscreen a core feature or nice-to-have? iOS failure response should match the answer.
- Who is the user in paused state? The near-invisible "Paused" and silence serve neither "commit to the breath" nor "pause freely" well.
- Does the orb size control earn its corner? A one-time home screen setup may serve the same need without fragmenting the meditation space on every session.
- What happens on session 100 vs session 1? The experience is identical — stats track milestones but the session itself doesn't acknowledge returning users.
